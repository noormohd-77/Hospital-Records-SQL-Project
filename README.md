# Hospital Records Analysis Using SQL

## Project Overview
This project focuses on analyzing hospital records using SQL queries to extract meaningful insights about patients, hospitals, departments, doctors, and medical expenses.
The project demonstrates practical SQL skills through 10 queries designed to answer common healthcare data analysis questions.

## Objectives
- Analyze the total number of patients across hospitals.
- Calculate the average number of doctors available in each hospital.
- Identify the top three departments by patient count.
- Find the hospital with the highest medical expenses.
- Calculate average daily medical expenses for each hospital.
- Identify the patient with the longest hospital stay.
- Analyze patient counts by city.
- Calculate the average length of stay by department.
- Identify the department with the fewest patients.
- Analyze monthly medical expenses.
